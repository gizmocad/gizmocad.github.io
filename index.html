AI assistant (MCP)

Let an AI assistant such as Claude build and change your model: describe a part, and watch it appear here. It connects through MCP (Model Context Protocol), using a small server that runs on your computer.

Set up once

  1. Install Node.js (version 18 or newer).
  2. and keep it somewhere safe, such as your home folder.
  3. Add it to your assistant, with the file's full path:
    Claude Code (in a terminal)

          Other MCP apps: run node gizmocad-mcp.mjs as a stdio server.

  4. Switch on Connect above, then ask the assistant to make something.

Everything it does is a normal step you can undo (Ctrl+Z). Only programs on this computer can connect: the server listens on 127.0.0.1 and only accepts GizmoCAD. Safari can't reach it from the website; use Chrome, Edge, Firefox or the desktop app.
